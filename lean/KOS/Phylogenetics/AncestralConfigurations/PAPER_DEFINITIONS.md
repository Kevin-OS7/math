# The Disanto–Rosenberg theorem in the paper's own terms

File: [`PaperDefinitions.lean`](PaperDefinitions.lean), namespace `KOS.AncestralConfigurations`. It imports `Main.lean` and leaves it and the statement file `ComparatorChallenges/AncestralConfigurations.lean` unchanged.

The statement `disanto_rosenberg` counts `BTree.rootConfigs T`, the isomorphism classes of non-trivial prunings of `T`. The manuscript argues informally that this number is `c*(r)` of Disanto and Rosenberg (Bull. Math. Biol. 81 (2019) 384–407). This file removes that informal step. It defines `C(r)`, `t_κ(X)`, `∼_κ` and `c*(r)` as the paper does, and proves

```lean
theorem paperRootConfigsNonequiv_eq_rootConfigs (T : BTree) :
    paperRootConfigsNonequiv T = T.rootConfigs

theorem disanto_rosenberg_paper (n : ℕ) (hn : 2 ≤ n) :
    IsGreatest {k | ∃ T : BTree, T.leaves = n ∧ paperRootConfigsNonequiv T = k} (drMax n)
```

The file also defines `C(κ)` from realizations, which is the actual definition in Section 2.3. It proves that this agrees with the recursion of Section 2.4 (`realizationConfigs_eq_configsAt`) and restates the theorem in those terms (`disanto_rosenberg_realizations`).

## Definition by definition

Quotations are from the open-access version, https://pmc.ncbi.nlm.nih.gov/articles/PMC5851864/.

**Trees, nodes, lineages.**
> "A labeled topology t of size |t| = n is a bifurcating rooted tree with n labeled leaves" (§2.1). "It is convenient to assign arbitrary labels to the internal nodes of t as well." "Each lineage (edge) of t is identified by the lowest node it intersects" (Fig. 1 caption).

A tree is a `BTree`. Its nodes are named by their paths from the root: `Node := List Bool`, with root `[]` and children `κ ++ [false]` (`κℓ`) and `κ ++ [true]` (`κr`). `BTree.nodesAt t κ` is the node set of the subtree `t` located at node `κ`, and `BTree.nodes T` is the node set of `T`. Gene lineages of `G = t` are named by nodes: `Lineage := Node`. A configuration is therefore a `Finset (List Bool)`.

**Subtrees.**
> "If κ is a node of a tree t, denote by tκ the subtree of t generated by κ (i.e., κ and all nodes below it)." (§3.1)

`BTree.subtree T κ` is `t_κ`. Every node-level definition takes the pair `(t_κ, κ)`, so its outputs are sets of nodes of the ambient tree. The paper works the same way: `C(rℓ)` consists of nodes of `t`.

**Configurations: the recursion of §2.4** (`otimes`, `BTree.configsAt`, `paperConfigs`).
> "If A, B are two sets of sets, define A ⊗ B = {a ∪ b : a ∈ A, b ∈ B}. For a given tree t with |t| > 1, the set C(r) of configurations at the root r of t satisfies the following decomposition
> C(r) = {{rℓ, rr}} ∪ [C(rℓ) ⊗ {{rr}}] ∪ [{{rℓ}} ⊗ C(rr)] ∪ [C(rℓ) ⊗ C(rr)],
> where rℓ and rr respectively denote the left and right children of r." (§2.4)
>
> "we say that a leaf or 1-taxon tree has 0 ancestral configurations" (§2.3)
>
> "the set C(κ) defined in (3) and its cardinality c(κ) (4) depend only on node κ and tree t." (§2.3)

`configsAt leaf κ = ∅`. For an internal node, `configsAt (node l r) κ` is the displayed formula with the four terms in the paper's order, where `C(κℓ) = configsAt l (κ ++ [false])` and `C(κr) = configsAt r (κ ++ [true])`. Since `C(κ)` depends only on `t_κ`, applying the display at every internal node is the paper's recursion. The root configurations are `paperConfigs T := T.configsAt []`.

**Restriction** (`BTree.restrictAt`, `restrict`).
> "If X is a set of nodes of a subtree tκ, the restriction tκ(X) of tκ to X is the tree shape obtained by removing from tκ all nodes that remain strictly below the nodes belonging to X." (§3.1)

`restrictAt` walks down from `κ`. A node in `X` keeps its place and loses everything below it; any other node keeps both children. `restrict T X := T.restrictAt [] X`. The definition does not use `prunings`. Two theorems show that it is the tree the sentence describes:

- `nodes_restrict`: `(restrict T X).nodes = T.nodes.filter (fun p => ¬ ∃ x ∈ X, x <+: p ∧ x ≠ p)`. The nodes that remain are those not strictly below a node of `X`. `nodesAt_restrictAt` is the version for `t_κ`.
- `nodes_injective`: a tree is determined by its node set.

**Equivalence and `c*`** (`rootConfigEquiv`, `paperRootConfigsNonequiv`; at any node: `configEquivAt`, `nonequivConfigsAt`).
> "two configurations γ1, γ2 at node κ, γ1, γ2 ∈ C(κ), are equivalent at κ—with the equivalence denoted by γ1 ∼κ γ2—when the tree shape tκ(γ1) is isomorphic to the tree shape tκ(γ2). [...] The set of non-equivalent configurations at a given node κ is denoted by C*(κ), and its cardinality is c*(κ) = |C*(κ)|" (§3.1)
>
> "we say that t1 is isomorphic to t2 and write t1 ≅ t2 when, after their leaf labels are removed, t1 and t2 have the same unlabeled topology." (§2.1)

The setoid on `{γ // γ ∈ paperConfigs T}` relates `γ₁` and `γ₂` when `BTree.Iso (restrict T γ₁) (restrict T γ₂)`. `Iso` is isomorphism of unordered rooted trees: children may be swapped at any node. The file proves that `Iso` is an equivalence relation (`Iso.refl/symm/trans`). `C*(κ)` has one representative per class, so `c*(r) := Nat.card (Quotient (rootConfigEquiv T))`. `nonequivConfigsAt_eq_rootConfigs` proves `c*(κ) = (T.subtree κ).rootConfigs` at every node.

**Realizations: the definition of §2.3** (`SpeciesTree`, `Realization`, `Realization.config`, `realizationConfigs`).
> "In our setting, exactly one gene lineage is selected from each species. We assume a matching labeled topology t for G and S. Consider a realization R of a gene tree G in a species tree S, with G = S = t (Fig. 1). Equivalently, R is one of the possible evolutionary scenarios for gene tree G on species tree S. Given a node κ of t, we denote by C(κ, R) the set of gene lineages, i.e. edges of G, that are present in S at the point right before node κ looking backward in time." "C(κ) = {C(κ, R) : R ∈ ℜ(G, S)}, (3)" "for each internal node κ, our definition of ancestral configuration excludes the case {κ} ∈ C(κ). This choice accords with the fact that each configuration at node κ is considered at the point right below node κ in the species tree, with no time for the gene lineages from the left and right subtrees of κ to coalesce together." (§2.3)

- **Species tree.** A `SpeciesTree T` assigns times `σ` (backward from the present) to nodes. Leaves are at 0 and parents are older than their children.
- **Realization.** A `Realization T S` assigns coalescence times `τ` to the nodes of `G = T`, with three conditions:
  - gene leaves are at time 0;
  - every gene node is older than its children;
  - `σ v < τ v` for every internal `v`: the two lineages that meet at gene node `v` come from the two sides of species node `v`, so they can only coalesce above it.
- **Configuration.** `R.config κ` is the set of lineages `u` strictly below `κ` with `τ u < σ κ ≤ τ (parent u)`. These are the lineages in the two branches below `κ` that exist at every time `σ κ − ε` for small `ε > 0`, which is the meaning of "right before κ". The exclusion of `{κ}` is not imposed by hand. Right before `κ`, the lineage `κ` does not exist yet, because its gene node coalesces only after `σ κ`; and it would not lie in a branch below `κ` anyway.
- **Set of configurations.** `realizationConfigs T S κ` is eq. (3), restricted to internal nodes `κ`, because a leaf has 0 configurations.

`realizationConfigs_eq_configsAt` proves, for every dated species tree `S` and every node `κ`, that `realizationConfigs T S κ = (T.subtree κ).configsAt κ`. This formalizes the step that the paper cites from Disanto and Rosenberg (2017), namely that C(r) "satisfies the following decomposition". `realizationRootConfigsNonequiv_eq_rootConfigs` and `disanto_rosenberg_realizations` then give the theorem with `C(r)` defined from realizations. That statement quantifies over all trees `T` and all speciation times `S`; `SpeciesTree.canonical` shows that every tree can be dated.

## What remains informal

1. **What a realization is.** The paper does not define realizations formally ("one of the possible evolutionary scenarios"). The constraints in `Realization` are our reading of that phrase. Our claim is that they describe the support of the multispecies coalescent when the gene tree topology is fixed to `G = t`. This claim is not formalized, because the multispecies coalescent is not. The choice of speciation times does not matter: every theorem holds for every `S`.
2. **"Right before node κ".** We read this as the times `σ κ − ε` for all small `ε > 0`, restricted to the two branches immediately below `κ`. A reading with "at time `σ κ`" would differ only when a coalescence time equals a speciation time exactly.
3. **Labeled topologies versus `BTree`.** The paper's trees are labeled topologies with unordered children; Lean uses plane trees. Labels serve only as names in all of the paper's definitions, and `≅` removes them. `paperRootConfigsNonequiv_iso` shows that `c*(r)` does not depend on which child is called left. So the maximum over trees of size `n` is the maximum over `BTree`s with `n` leaves. This identification is not formalized, because labeled topologies are not defined in Lean.
4. **Leaves.** "A leaf has 0 configurations" is the paper's convention and is imposed as such. It does not affect `c*(r)` for `n ≥ 2`.
5. **`drMax`.** `drMax` comes from the existing statement file (natural-number division is the floor in eq. (16)). It is checked here only against the Fig. 5 values.
